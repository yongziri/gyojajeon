# 사라진 바다 — 아랄해, 그리고 우리들의 이야기

> **세계시민교육(GCE)** 컨셉의 교육용 픽셀 RPG  
> 제20회 디지털교육연구대회 / 교육자료전 출품작  
> 공도중학교 이용빈

플레이어는 한국에서 온 학생이 되어 카라칼팍 마을의 안내자 **아이졸리**를 만난다.
사막 한가운데에 멈춰선 녹슨 배(무이낙)에서 시작해, 한때 세계에서 네 번째로 큰 호수였던
**아랄해**가 어떻게 사라졌는지, 그리고 그 일이 우리의 옷·물·일상과 어떻게 연결되어 있는지를
대화·조사·문제 풀이를 통해 배우고, 마지막에 UN에 직접 **편지**를 써서 전한다.

## 🎯 학습 모델 — P.E.A.C.E. × UNESCO 세계시민교육(GCED)

### 1) P.E.A.C.E. 5요소 (학습자 사고 흐름)
| 약자 | 의미 | 게임 안 활동 |
|---|---|---|
| **P** Perceiving | 인식 | 라일라(아이졸리)와의 첫 만남 |
| **E** Exploring | 탐색 | 옛 항구·지도실·시장 현장 조사 |
| **A** Analyzing | 분석 | 시민 인터뷰 + 문제 풀이로 핵심 단서 |
| **C** Connecting | 연결 | 🪞 성찰의 의자 — 인과 사슬 + 자기성찰 |
| **E** Enacting | 실천 | UN 조사 보고서 작성·송부 |

→ 4단계 수업 흐름(인식·관찰·성찰·실천)에 PEACE 5요소가 매핑됨.
   상세는 [PEACE_학습모델_매핑.txt](PEACE_학습모델_매핑.txt) 참조.

|---|---|---|

## 🎮 4단계 학습 흐름

게임은 **인식·관찰·탐구·실천**(I-O-I-P) 4단계로 설계되어 있으며, 학생 진행 상황이 HUD 상단의 단계 칩과 교사 대시보드에 실시간 표시됩니다.

```
[1단계 · 인식 Recognition]
   라일라(아이졸리)와 대화 → 마을·아랄해의 배경 인식
   ↳ 메타인지 발문: "가장 마음에 남은 한 마디는?"
      ↓
[2단계 · 관찰 Observation]
   옛 항구 · 지도실 · 소금먼지 마을 현장 조사 → 단서 ≥3 수집
   ↳ 메타인지 발문: "왜 이렇게 됐을까?를 가장 잘 설명하는 단서는?"
      ↓
[3단계 · 탐구 Inquiry]
   시민 NPC 3명 인터뷰(어부 · 상인 · 의사) → 객관식 문제 풀이
   → 핵심 단서 3개 획득
   ↳ 메타인지 발문: "내가 할 수 있는 일은 무엇일까?"
      ↓
[4단계 · 실천 Practice]
   UN 조사 보고서 작성 → 송부 → 캡처본을 학습 결과물로 제출
```

단계 전환 시 픽셀 카드가 떠오르며 **메타인지 발문**(학생 스스로의 사고를 점검) 한 문장이 함께 표시됩니다.

## 🏫 교사 활용 가이드 (50분 수업)

| 단계 | 시간 | 교사 활동 | 학생 활동 |
|---|---|---|---|
| 도입 | 5분 | "사라진 바다" 사진 1장 + 발문<br>"세계에서 4번째로 큰 호수가 90% 사라졌다면?" | 자유 발표 |
| 전개 ① | 10분 | 게임 1·2단계 안내, 단서 5개 이상 권장 | 라일라 대화 → 현장 조사 |
| 전개 ② | 15분 | 게임 3단계 — 단서로 시민 문제 풀이 유도 | 시민 인터뷰 + 객관식 |
| 전개 ③ | 10분 | 게임 4단계 — UN 보고서 작성, 다양한 다짐 격려 | 보고서 캡처본 제출 |
| 정리 | 10분 | **교사 대시보드**로 전체 진행 확인 → 보고서 1~2개 공유 → 토론 | 동료 평가, 다짐 발표 |

### 📡 교사 실시간 대시보드 (선택)

`dashboard.html` 을 브라우저로 열면 학급 학생들의 진행 단계·단서 수집 수가 실시간으로 보입니다 (MQTT broker.emqx.io 무료 공용 브로커 사용).

```
1. 학생: index.html 상단 "참가번호 / 교실 코드" 입력 후 게임 시작
2. 교사: dashboard.html 열고 같은 교실 코드 입력
3. 자동으로 각 학생의 단계 칩(인식·관찰·탐구·실천)이 갱신됨
```

> 인터넷이 차단된 학교 환경에서는 자동으로 무시되며 게임 진행에는 영향 없음(fail-silent).

## 📋 평가 루브릭 (예시)

게임 종료 후 학생이 송부한 **UN 조사 보고서 캡처본**과 정리 단계 토론을 바탕으로 평가합니다.

| 평가 요소 | 우수 (3점) | 보통 (2점) | 노력 필요 (1점) |
|---|---|---|---|
| **사실 이해** (인지) | 강물 우회·아랄쿰 사막·건강 피해를 인과로 설명 | 두 요소 설명 | 한 요소만 단편적 설명 |
| **공감** (정서) | 마을 4만 명의 삶 변화를 자기 언어로 진술 | 변화 사실 인지 | 정보 나열만 |
| **연결 의식** (인지) | 내 옷 한 벌과 아랄해 강물의 연결 설명 | 연결 인지만 | 인지하지 못함 |
| **실천 다짐** (행동) | 구체적·현실적 실천(예: 의류 소비, 정보 공유) | 추상적 다짐 | 다짐 없음 |
| **국제 협력 이해** (행동) | 코카랄 댐·UN 등 국제 협력 사례 인용 | 사례 1개 | 언급 없음 |

총 15점 / 5단계 5개 항목 × 3점. 학교·차시에 맞게 가중치 조정 가능.

## 🛠 다른 PC에서 실행하는 방법

### 사전 준비
**Node.js (LTS 권장, 18+)** 만 있으면 됩니다.
- 다운로드: https://nodejs.org/

### 설치 & 실행

```bash
# 1. 프로젝트 폴더로 이동
cd vanished-sea         # 또는 폴더 이름

# 2. 의존성 설치 (한 번만, 약 30초~1분)
npm install

# 3. 게임 실행
npm start
```

처음 실행 시 Electron이 자동 다운로드되며 게임 창이 뜹니다.

### 폴더 통째로 옮기는 경우
`node_modules/` 폴더는 빼고 전송하셔도 됩니다(`npm install`로 재생성됨).
용량이 작아지고 OS·CPU 종속성도 줄어듭니다.

```
✅ 함께 보낼 폴더·파일
   ├─ src/          (게임 코드)
   ├─ assets/       (그림·폰트·사진·스프라이트)
   ├─ index.html
   ├─ main.js       (Electron 진입점)
   ├─ package.json
   ├─ package-lock.json
   ├─ README.md
   ├─ DEVELOPMENT_LOG.md
   └─ .gitignore

❌ 안 보내도 되는 폴더
   └─ node_modules/  (npm install로 재생성)
   └─ dist/          (빌드 결과물)
```

## ✏️ 콘텐츠 수정 (코드 몰라도 가능)

게임의 모든 텍스트·문제는 **데이터 파일**로 분리되어 있습니다.
`src/` 폴더의 세 파일만 고치면 됩니다.

| 파일 | 무엇이 들어 있나 | 어떻게 고치나 |
|---|---|---|
| `src/dialogue.js` | 아이졸리와의 대화 (인사·역사·문화·엔딩) | 따옴표 안 글자 변경, 노드 복사로 추가 |
| `src/cases.js` | 옛 항구·지도실·시장의 조사 지점·증거 | 좌표 / 텍스트 / 단서 명 변경 |
| `src/quizzes.js` | 시민 NPC 3명·인트로 대사·문제·정답·보상 | 시민 칸 추가/수정, 보기 문구 변경 |

각 파일 맨 위에 작성법 주석이 있습니다.

## 📦 배포 & 패키징

다른 PC에 공유하려면 두 가지 방법이 있습니다.

### A) 포터블 .exe (다른 사람용, 추천)
```bash
npm install --save-dev electron-builder   # 처음 한 번만
npm run dist
```
`release/` 폴더에 `VanishedSea.exe` + 의존 파일이 생성됩니다.
폴더 통째로 ZIP으로 묶어 보내면 받는 사람은 압축 풀고 `.exe` 더블클릭 → 실행.

### B) 소스 그대로 (개발자용)
```bash
git clone <repo>
npm install
npm start
```

배포 ZIP 예시:
```
사라진바다_배포.zip  (약 130MB)
├─ VanishedSea.exe        ← 더블클릭으로 게임 실행
├─ dashboard.html         ← 교사용 실시간 대시보드
├─ 실행방법.txt
├─ PEACE_학습모델_매핑.txt
└─ (Electron 의존 파일들)
```

  → 단서 3개 + 인과 사슬 + 자기성찰 + 다짐 + 자기평가 점수 + 획득 뱃지가 모두 들어간 A4 1쪽 보고서. **PDF 저장 가능**.
- **학급 리포트**: `dashboard.html`의 `🖨 학급 리포트` 버튼
  → 학급 전체 진행 요약 + 감정 태그 분포 + 학생별 학습 흔적 표.
