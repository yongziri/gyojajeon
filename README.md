# 사라진 바다 — 아랄해, 그리고 우리들의 이야기

> **세계시민교육(GCE)** 컨셉의 교육용 픽셀 RPG  
> 제20회 디지털교육연구대회 / 교육자료전 출품작  
> 공도중학교 이용빈

플레이어는 한국에서 온 학생이 되어 카라칼팍 마을의 안내자 **아이졸리**를 만난다.
사막 한가운데에 멈춰선 녹슨 배(무이낙)에서 시작해, 한때 세계에서 네 번째로 큰 호수였던
**아랄해**가 어떻게 사라졌는지, 그리고 그 일이 우리의 옷·물·일상과 어떻게 연결되어 있는지를
대화·조사·문제 풀이를 통해 배우고, 마지막에 UN에 직접 **편지**를 써서 전한다.

---

## 🎯 교육적 프레임 — UNESCO 세계시민교육 3대 영역

| 영역 | 게임 단계 |
|---|---|
| **인지적** (지식·비판적 사고) | 아이졸리 대화 + 옛 항구·지도실·시장 조사로 사실·인과 학습 |
| **사회-정서적** (공감·다양성) | 옛 어부·옷가게 상인·의사 등 마을 시민과 대화 |
| **행동적** (책임감·참여) | 시민이 낸 문제 풀이 → 핵심 단서 → **UN 편지** 작성·출력 |

이론 근거: 박미정 (2022) 「다문화사회의 세계시민교육 방안 연구」, 한국이민정책학보 5(2), 87-105.

## 🎮 게임 흐름

```
[1] 라일라(아이졸리)와 대화로 역사·문화 배우기
      ↓
[2] 옛 항구·지도실·시장 조사 → 단서 수집
      ↓
[3] 마을 시민 NPC 3명과 대화 (어부 / 상인 / 의사)
      ↓ 시민이 문제(객관식) 제시
[4] 조사 단서를 힌트로 문제 풀어 "핵심 단서" 획득
      ↓
[5] 핵심 단서 3개 모이면 UN 편지 잠금 해제
      ↓
[6] 받는 곳·사실·다짐 선택해 편지 완성 → 출품 결과물 캡처
```

## 🛠 다른 PC에서 실행하는 방법

### 사전 준비
**Node.js (LTS 권장, 18+)** 만 있으면 됩니다.
- 다운로드: https://nodejs.org/

### 설치 & 실행

```bash
# 1. 프로젝트 폴더로 이동
cd vanished-sea         # 또는 폴더 이름

# 2. 의존성 설치 (한 번만, 약 30초~1분)
npm install

# 3. 게임 실행
npm start
```

처음 실행 시 Electron이 자동 다운로드되며 게임 창이 뜹니다.

### 폴더 통째로 옮기는 경우
`node_modules/` 폴더는 빼고 전송하셔도 됩니다(`npm install`로 재생성됨).
용량이 작아지고 OS·CPU 종속성도 줄어듭니다.

```
✅ 함께 보낼 폴더·파일
   ├─ src/          (게임 코드)
   ├─ assets/       (그림·폰트·사진·스프라이트)
   ├─ index.html
   ├─ main.js       (Electron 진입점)
   ├─ package.json
   ├─ package-lock.json
   ├─ README.md
   ├─ DEVELOPMENT_LOG.md
   └─ .gitignore

❌ 안 보내도 되는 폴더
   └─ node_modules/  (npm install로 재생성)
   └─ dist/          (빌드 결과물)
```

## ✏️ 콘텐츠 수정 (코드 몰라도 가능)

게임의 모든 텍스트·문제는 **데이터 파일**로 분리되어 있습니다.
`src/` 폴더의 세 파일만 고치면 됩니다.

| 파일 | 무엇이 들어 있나 | 어떻게 고치나 |
|---|---|---|
| `src/dialogue.js` | 아이졸리와의 대화 (인사·역사·문화·엔딩) | 따옴표 안 글자 변경, 노드 복사로 추가 |
| `src/cases.js` | 옛 항구·지도실·시장의 조사 지점·증거 | 좌표 / 텍스트 / 단서 명 변경 |
| `src/quizzes.js` | 시민 NPC 3명·인트로 대사·문제·정답·보상 | 시민 칸 추가/수정, 보기 문구 변경 |

각 파일 맨 위에 작성법 주석이 있습니다.
