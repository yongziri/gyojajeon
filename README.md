# P.E.A.C.E. — 통(通)하는 국제 분쟁 탐구하기

> **세계시민교육(GCED)** 컨셉의 교육용 픽셀 RPG
> **제73회 경기도교육자료전 (사회·역사 분야) 출품작**
> 공도중학교 (안성교육지원청) — **공동제작: 염태철(대표) · 이문호 · 이용빈**

플레이어는 UN 조사관이 되어 **세 가지 국제 분쟁 현장**을 차례로 조사한다:

1. **사라진 바다 — 아랄해 환경 분쟁** (안내자 아이졸리)
2. **깨어진 평화 — 러시아·우크라이나 전쟁** (안내자 카테리나)
3. **오래된 갈등 — 팔레스타인·이스라엘** (안내자 카림)

각 현장에서 사람들과 만나고, 단서를 모으고, 인과 사슬을 잇고, 마지막에 UN에 **조사 보고서와 연설문**을 송부한다. 분쟁의 원인이 멀리 있지 않다는 것 — 우리의 옷·식탁·이웃과 어떻게 연결되어 있는지 — 을 배우는 게 목표.

라이브 데모: **https://yongziri.github.io/gyojajeon/**

## 🎯 학습 모델 — P.E.A.C.E. × UNESCO 세계시민교육(GCED)

### 1) P.E.A.C.E. 5단계 (학습자 사고 흐름)
| 약자 | 의미 | 게임 안 활동 |
|---|---|---|
| **P** Perceiving | 인식 | 사건 선택 → 안내자(아이졸리·카테리나·카림)와 첫 만남 |
| **E** Exploring | 탐색 | 사건별 3개 현장 조사 (단서 12개 / 실사 사진 9장) |
| **A** Analyzing | 분석 | 시민 NPC 3명 인터뷰 + 객관식 → 핵심 단서 3개 |
| **C** Connecting | 연결 | 🪞 성찰의 의자 — 인과 사슬 + 자기성찰 카드 + 본인 한 문장 |
| **E** Enacting | 실천 | UN 조사 보고서 송부 + **UN 연설문** 작성 |

→ 상세 매핑: [PEACE_학습모델_매핑.txt](PEACE_학습모델_매핑.txt)

### 2) 5차원 자동 평가 (P.E.A.C.E. 평가 시스템)
게임이 학생 활동을 5차원으로 자동 채점 → 교사 대시보드·인쇄 보고서에 표시.

| 차원 | 점수 기준 (각 0~3점) |
|---|---|
| **Empathy** 공감 | 안내자와의 대화 이해도 (love 누적) |
| **Cognition** 사실 이해 | 현장 단서 + 핵심 단서 수집량 |
| **Connection** 연결 의식 | 인과 사슬 + 자기성찰 카드 + 본인 한 문장 |
| **Action** 실천 다짐 | UN 보고서 + UN 연설문 완성 |
| **Cooperation** 국제 협력 | 사건별 "협력의 손길" 단서 2종 + 보고서 송부 |

**총 15점 / 등급 S(13+) · A(10+) · B(7+) · C**

### 3) UNESCO GCED 3영역 (단서 색상 배지)
| 영역 | 배지 | 게임 내 역할 |
|---|---|---|
| **인지적** Cognitive | 🔵 | 사실·메커니즘·상호의존성 |
| **사회-정서적** Socio-emotional | 🟠 | 현장 사람들의 삶에 공감 |
| **행동적** Behavioral | 🟢 | 해결을 위한 국제 협력·실천 |

### 4) 자기조절학습(SRL) 사이클
| 단계 | 게임 안 요소 |
|---|---|
| 목표 설정 | 사건 선택 + 임무 브리핑 (미니맵 표시) |
| 실행·전략 | 단서·시민 인터뷰 순서 자유, 단계 칩 실시간 표시 |
| 자기 모니터링 | 💭 단서별 감정 태그 (5택) |
| 자기 평가 | 📊 임무 회고 루브릭 — ★ 3개 슬라이더 + "더 알고 싶은 것" |
| 누적 포트폴리오 | 🌳 학습 트리 — 사건별 인과 사슬·자기성찰·5차원 평가·뱃지 |

## 🎮 게임 흐름 (사건 1건 기준)

```
[ TitleScene ]
   └ ❓ 도움말 · 📑 교육과정 연계 · 🎓 교사 가이드 · 🎵 음소거
       ↓
[ CaseSelectScene ]  세계지도에서 사건 마커 클릭 (3개 사건)
       ↓
[ BriefingScene ]    사건 미니맵 + 임무 브리핑
       ↓
[ WorldScene ]       (이하 사건 1건의 4단계가 순환)

  [ P 인식 ]   안내자(아이졸리/카테리나/카림)와 첫 만남
   └ DialogueScene — 10단계 대화, 선택지에 따라 이해도 누적

  [ E 탐색 ]   노란 표지판 → InvestigationScene
   └ 3개 장소 × 4개 단서 = 12개 (감정 태그도 함께)

  [ A 분석 ]   3명 시민 NPC 인터뷰
   └ QuizScene — 객관식 → 정답이면 핵심 단서 획득

  [ C 성찰 ]   🪞 성찰의 의자
   └ ReflectionScene — 인과 사슬 [원인→중간→결과] + 자기성찰 카드 + 본인 한 문장

  [ E 실천 ]   📮 우편함
   └ LetterScene — UN 보고서 작성·송부
   └ SpeechScene — UN 연설문 (본문 3문장 + 마무리)
       ↓
[ LearningTreeScene ]  사건별 5차원 점수·뱃지·인쇄 보고서
```

단계 전환 시 픽셀 카드가 떠오르며 **메타인지 발문** 한 문장이 표시.

## 🏫 교사 활용 가이드

### A. 한 사건 집중 (1차시 50분)
| 단계 | 시간 | 교사 활동 | 학생 활동 |
|---|---|---|---|
| 도입 | 5분 | 사건 사진 1장 + 발문 ("왜 이런 일이 일어났을까?") | 자유 발표 |
| 전개 ① | 10분 | 안내인 대화 → 현장 조사 1·2단계 | DialogueScene + InvestigationScene |
| 전개 ② | 15분 | 시민 인터뷰 → 핵심 단서 3개 | QuizScene |
| 전개 ③ | 10분 | 🪞 성찰 + 📮 보고서 + 🕊 연설문 | Reflection + Letter + Speech |
| 정리 | 10분 | **교사 대시보드**로 학급 현황 확인 → 보고서 1~2개 공유 | 동료 평가, 발표 |

### B. 3사건 통합 패키지 (2~3차시)
사건 3개를 차례로 또는 모둠별로 분담해 진행. 마지막에 학습 트리에서 5차원 누적 비교.

### 📡 교사 실시간 대시보드
`dashboard.html`을 브라우저로 열면 학급 학생들의 진행 단계·단서 수집 수가 실시간으로 보임 (MQTT broker.emqx.io 무료 공용 브로커 사용).

```
1. 학생: index.html 상단 "참가번호 / 교실 코드" 입력 후 게임 시작
2. 교사: dashboard.html 열고 같은 교실 코드 입력
3. 자동으로 각 학생의 P.E.A.C.E. 5차원 점수·정체 여부가 갱신됨
4. 📋 버튼으로 학급 CSV 내보내기 (UTF-8 BOM, Excel 호환)
```

인터넷이 차단된 학교 환경에서는 자동으로 무시되며 게임 진행에는 영향 없음(fail-silent).

## 🛠 실행 방법

### A. 모바일·태블릿 (PWA / APK)
- 브라우저: https://yongziri.github.io/gyojajeon/ 접속 → "홈 화면에 추가"
- 안드로이드 APK: PWABuilder로 빌드된 .apk를 사이드로드 (별도 배포)

### B. PC (Electron, 개발용)
**Node.js 18+** 필요. https://nodejs.org/

```bash
cd rpg-demo
npm install     # 한 번만 (약 30초~1분)
npm start       # Electron 창이 뜸
```

`node_modules/` 는 전송 시 제외 가능 (`npm install`로 재생성).

## ✏️ 콘텐츠 수정 (코드 몰라도 가능)

게임의 모든 텍스트·문제·단서는 **데이터 파일**로 분리. `src/` 폴더의 세 파일만 고치면 됨.

| 파일 | 들어있는 것 | 어떻게 고치나 |
|---|---|---|
| `src/dialogue.js` | 사건별 안내자(STORIES.aralsea/ukraine/palestine) 대화 | 따옴표 안 글자 변경 |
| `src/cases.js` | 사건별 조사 장소·단서 (CASES.*) — 위치 좌표·이름·desc | 좌표 / 텍스트 변경 |
| `src/quizzes.js` | 사건별 시민 NPC·문제·정답·보상 (CITIZENS_BY_CASE.*) | 시민 칸 추가/수정 |

각 파일 맨 위에 작성법 주석.
