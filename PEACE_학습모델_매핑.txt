■ 1. P.E.A.C.E. 학습 모델이란?
   ─────────────────────────────────────────────────────────────

   다문화·세계시민교육 수업을 학생의 사고 흐름에 맞춰 5단계
   인지 활동으로 구조화한 모델.

       ┌── 인식 ──┐ ┌── 관찰 ────────┐ ┌── 성찰 ──┐ ┌── 실천 ──┐
       │    P     │ │    E      A    │ │     C    │ │     E    │
       │Perceiving│ │Exploring  Anal.│ │Connecting│ │ Enacting │
       └──────────┘ └────────────────┘ └──────────┘ └──────────┘

   - P  Perceiving (인식)   : 문제 상황을 알아차린다.
   - E  Exploring  (탐색)   : 자료·현장에서 사실을 찾는다.
   - A  Analyzing  (분석)   : 사실을 비교·검토해 의미를 짚는다.
   - C  Connecting (연결)   : 흩어진 정보를 큰 그림으로 잇는다.
   - E  Enacting   (실천)   : 배운 것을 행동으로 옮긴다.

   수업단계(외부) 4단계와 PEACE(내부) 5요소가 다음과 같이 묶임:
        수업단계 「인식 → 관찰 → 성찰 → 실천」
                   P      E·A      C      E


■ 2. 게임 4단계 ↔ PEACE 매핑
   ─────────────────────────────────────────────────────────────

   ┌─[1] 인식 (Perceiving) ─────────────────────────────────────┐
   │  📚 학생 활동                                              │
   │    · 안내인 라일라(아이졸리)와 대화                         │
   │    · 카라칼팍 마을·아랄해의 역사·문화 배경 인식             │
   │  🎯 학습 성과                                              │
   │    · 사건의 존재와 규모를 인지한다.                         │
   │  ✓ 다음 단계 진입 조건                                     │
   │    · 라일라와 첫 대화 종료 (enemyDefeated = true)           │
   └────────────────────────────────────────────────────────────┘

   ┌─[2] 관찰 (Exploring + Analyzing) ──────────────────────────┐
   │  📚 학생 활동 (E·A 두 활동을 차례로 진행)                   │
   │                                                            │
   │   [E] Exploring  ── 현장 조사                              │
   │      · 옛 항구·지도실·시장 3장소에서 단서 수집               │
   │      · 단서 ≥3 모이면 시민 인터뷰 잠금 해제                │
   │                                                            │
   │   [A] Analyzing  ── 시민 인터뷰 + 문제 풀이                │
   │      · 옛 어부·옷가게 상인·마을 의사 3명과 인터뷰          │
   │      · 모은 단서를 힌트로 객관식 문제 풀어 핵심 단서 획득   │
   │                                                            │
   │  🎯 학습 성과                                              │
   │    · 사실(현장 단서) + 인터뷰(생활인 증언)을 통합한다.      │
   │  ✓ 다음 단계 진입 조건                                     │
   │    · 현장 단서 ≥ 3개  AND  핵심 단서 = 3개                  │
   └────────────────────────────────────────────────────────────┘

   ┌─[3] 성찰 (Connecting) ─────────────────────────────────────┐
   │  📚 학생 활동  ── "성찰의 의자" 트리거 진입                 │
   │                                                            │
   │   ❶ 인과 사슬 만들기                                       │
   │      · 모은 단서 중 3개를 골라 순서대로 배치                │
   │      ·  [원인]  →  [중간]  →  [결과]                       │
   │      · 권장 답안에 ★ 표시 (정답이 하나는 아님)               │
   │                                                            │
   │   ❷ 자기성찰 (한 문장)                                     │
   │      · "가장 마음에 남은 단서는 무엇이며, 왜인가요?"        │
   │      · 5개 보기 카드 중 1개 선택                            │
   │                                                            │
   │  🎯 학습 성과                                              │
   │    · 흩어진 사실을 인과 관계로 연결한다.                    │
   │    · 자기 자신의 정서적 반응을 메타인지로 인식한다.         │
   │  ✓ 다음 단계 진입 조건                                     │
   │    · 인과 사슬 3개 배치 완료 + 자기성찰 카드 1개 선택       │
   │      (reflectionDone = true)                               │
   └────────────────────────────────────────────────────────────┘

   ┌─[4] 실천 (Enacting) ───────────────────────────────────────┐
   │  📚 학생 활동                                              │
   │    · 파란 우편함 진입 → UN 조사 보고서 작성                 │
   │    · 받는 곳·사실 단서 3개·다짐 3개·성찰 1문장 자동 인용     │
   │    · 송부 → 캡처 → 출품 결과물                              │
   │  🎯 학습 성과                                              │
   │    · 배운 것을 책임 있는 시민 행동으로 옮긴다.              │
   │  ✓ 종료 조건                                               │
   │    · 보고서 송부 → completedCases에 사건 등록 → ★ 완료      │
   └────────────────────────────────────────────────────────────┘


■ 3. UNESCO 세계시민교육(GCED) 3영역과의 결합
   ─────────────────────────────────────────────────────────────

   PEACE 단계가 "사고 흐름"이라면 GCED 3영역은 "내용 분류".
   두 축이 직교(orthogonal)하므로 단계마다 영역이 섞임.

       PEACE \ GCED  │ 인지(■파랑)  정서(■주황)  행동(■초록)
       ──────────────┼─────────────────────────────────────────
       P 인식        │              ●
       E 탐색        │     ●        ●
       A 분석        │     ●        ●
       C 성찰        │     ●        ●            ●(맹아)
       E 실천        │                            ●

   · 게임 내 단서 13개(현장 10 + 핵심 3) 모두 area 태그 부착
   · 색상 배지로 학생이 어떤 영역의 학습인지 즉시 인지


■ 4. 교사 수업 활용 흐름 (50분 1차시)
   ─────────────────────────────────────────────────────────────

   시간    수업단계       PEACE           학생 활동
   ─────   ────────────   ────────────    ───────────────────
    5분    도입           ─                동기 유발 사진·발문
   10분    인식(전개①)   P                라일라 대화
   15분    관찰(전개②)   E → A            현장 조사 → 시민 인터뷰
   10분    성찰(전개③)   C                인과 사슬 + 자기성찰
   10분    실천(전개④)   E                UN 보고서 작성·송부
   ────────────────────────────────────────────────────────────
   ※ 교사 실시간 대시보드(dashboard.html)로 학급 진행도 추적
   ※ 게임 내 「📑 교육과정 연계표」 화면을 자료집에 캡처 가능


■ 5. 2022 개정 교육과정 성취기준 매핑
   ─────────────────────────────────────────────────────────────

   [9사(지리)07-03]  세계의 환경 문제와 지속가능한 발전을 위한
                     시민의 참여 방안을 탐구한다.        → P·E·A·E
   [9사(지리)12-01]  지구적 차원의 자원 문제와 국제 협력의
                     필요성을 이해한다.                  → A·C
   [9도03-02]        세계 시민으로서의 도덕적 책임을 인식하고
                     실천 방안을 모색한다.               → C·E
   [9도03-03]        문화 다양성을 존중하고 평화로운 공존을
                     추구한다.                           → P
   범교과   환경·지속가능발전, 다문화·세계시민 교육      → 전 단계


■ 6. 평가 루브릭 (요약)
   ─────────────────────────────────────────────────────────────

   평가 항목                            관련 단계   배점
   ────────────────────────────────     ─────────   ────
   사실 이해 (인과 메커니즘 설명)        E·A·C      3점
   공감 (마을 사람들 삶 진술)            P·A         3점
   연결 의식 (내 옷과 강물의 관계)       A·C         3점
   실천 다짐 (구체적·현실적 행동)        E (Enacting) 3점
   국제 협력 이해 (코카랄·UN 사례)       C·E         3점

                                          총점     15점
