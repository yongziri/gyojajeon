■ 1. P.E.A.C.E. 학습 모델이란?
   ─────────────────────────────────────────────────────────────

   다문화·세계시민교육 수업을 학생의 사고 흐름에 맞춰 5단계
   인지 활동으로 구조화한 모델.

       ┌── 인식 ──┐ ┌── 관찰 ────────┐ ┌── 성찰 ──┐ ┌── 실천 ──┐
       │    P     │ │    E      A    │ │     C    │ │     E    │
       │Perceiving│ │Exploring  Anal.│ │Connecting│ │ Enacting │
       └──────────┘ └────────────────┘ └──────────┘ └──────────┘

   - P  Perceiving (인식)   : 문제 상황을 알아차린다.
   - E  Exploring  (탐색)   : 자료·현장에서 사실을 찾는다.
   - A  Analyzing  (분석)   : 사실을 비교·검토해 의미를 짚는다.
   - C  Connecting (연결)   : 흩어진 정보를 큰 그림으로 잇는다.
   - E  Enacting   (실천)   : 배운 것을 행동으로 옮긴다.

   수업단계(외부) 4단계와 PEACE(내부) 5요소가 다음과 같이 묶임:
        수업단계 「인식 → 관찰 → 성찰 → 실천」
                   P      E·A      C      E


■ 2. 게임 구조 — 3사건 통합
   ─────────────────────────────────────────────────────────────

   학생은 UN 조사관이 되어 세 가지 국제 분쟁을 차례로 조사한다.
   동일한 P.E.A.C.E. 5단계 흐름이 사건마다 반복되며, 각 사건의
   문제 영역이 달라 학습 폭이 넓어진다.

       사건 1  사라진 바다     아랄해 환경 분쟁        안내인 아이졸리
                              (강조: 환경·소비·국제기구)
       사건 2  깨어진 평화     러시아·우크라이나 전쟁   안내인 카테리나
                              (강조: 식량·에너지·평화 교육)
       사건 3  오래된 갈등     팔레스타인·이스라엘     안내인 카림
                              (강조: 평화·인도주의·세 종교 공존)

   학생은 한 사건만 깊이 또는 세 사건을 차례로 진행할 수 있다.
   학습 트리에 사건별 4차원 점수가 누적된다.


■ 3. 게임 4단계 ↔ PEACE 매핑 (각 사건 공통)
   ─────────────────────────────────────────────────────────────

   ┌─[1] 인식 (Perceiving) ─────────────────────────────────────┐
   │  📚 학생 활동                                              │
   │    · 임무 선택 → 안내인과 첫 만남                          │
   │    · 사건의 역사·문화 배경 인식 (10단계 대화)              │
   │  🎯 학습 성과                                              │
   │    · 사건의 존재와 규모를 인지한다.                        │
   │  ✓ 다음 단계 진입 조건                                     │
   │    · 안내인과 첫 대화 종료 (enemyDefeated = true)          │
   └────────────────────────────────────────────────────────────┘

   ┌─[2] 관찰 (Exploring + Analyzing) ──────────────────────────┐
   │  📚 학생 활동 (E·A 두 활동을 차례로 진행)                  │
   │                                                            │
   │   [E] Exploring  ── 현장 조사                              │
   │      · 사건별 3개 장소 × 4개 단서 = 12개 단서 수집          │
   │      · 실사 풍 픽셀 사진 배경 9장 (사건별 3장)             │
   │      · 단서 ≥3 모이면 시민 인터뷰 잠금 해제                │
   │                                                            │
   │   [A] Analyzing  ── 시민 인터뷰 + 문제 풀이                │
   │      · 사건별 시민 NPC 3명과 인터뷰                        │
   │      · 모은 단서를 힌트로 객관식 문제 풀어 핵심 단서 획득  │
   │                                                            │
   │  🎯 학습 성과                                              │
   │    · 사실(현장 단서) + 인터뷰(생활인 증언)을 통합한다.     │
   │  ✓ 다음 단계 진입 조건                                     │
   │    · 현장 단서 ≥ 3개  AND  핵심 단서 = 3개                  │
   └────────────────────────────────────────────────────────────┘

   ┌─[3] 성찰 (Connecting) ─────────────────────────────────────┐
   │  📚 학생 활동  ── "성찰의 의자" 트리거 진입                │
   │                                                            │
   │   ❶ 인과 사슬 만들기                                       │
   │      · 모은 단서 중 3개를 골라 순서대로 배치               │
   │      ·  [원인]  →  [과정]  →  [결과]                       │
   │      · 권장 답안에 ★ 표시 (정답이 하나는 아님)              │
   │                                                            │
   │   ❷ 자기성찰 (한 문장)                                     │
   │      · 사건별 5장 카드 중 1개 선택                          │
   │      · "가장 마음에 남은 단서는 무엇이며, 왜인가요?"        │
   │                                                            │
   │   ❸ 본인 작성 (선택)                                       │
   │      · 학생이 직접 한 문장 적을 수 있음 (자유 입력 ≤200자) │
   │      · 인쇄 보고서·교사 대시보드에 인용                     │
   │                                                            │
   │  🎯 학습 성과                                              │
   │    · 흩어진 사실을 인과 관계로 연결한다.                   │
   │    · 자기 자신의 정서적 반응을 메타인지로 인식한다.        │
   │  ✓ 다음 단계 진입 조건                                     │
   │    · 인과 사슬 3개 배치 완료 + 자기성찰 카드 1개 선택      │
   │      (reflectionDone = true)                               │
   └────────────────────────────────────────────────────────────┘

   ┌─[4] 실천 (Enacting) ───────────────────────────────────────┐
   │  📚 학생 활동                                              │
   │                                                            │
   │   ❶ UN 조사 보고서 작성·송부                                │
   │      · 사건별 수신처·다짐 목록 (3종) — 환경부/외교부/UNRWA  │
   │      · 받는 곳·사실 단서 3개·다짐 3개·성찰 1문장 자동 인용 │
   │      · 송부 → 캡처 → 출품 결과물                            │
   │                                                            │
   │   ❷ UN 연설문 작성 (마지막 E — Enacting)                   │
   │      · 본문 문장 6장 중 3개 선택 + 마무리 문장 3장 중 1개   │
   │      · 한 짧은 연설로 평화 메시지 완성                      │
   │                                                            │
   │  🎯 학습 성과                                              │
   │    · 배운 것을 책임 있는 시민 행동으로 옮긴다.             │
   │    · 공감을 공적 발화로 변환한다.                          │
   │  ✓ 종료 조건                                               │
   │    · 보고서 송부 + 연설문 작성 → ★ 완료                     │
   │    · completedCases에 사건 등록                            │
   └────────────────────────────────────────────────────────────┘


■ 4. P.E.A.C.E. 4차원 자동 평가 (게임 내장)
   ─────────────────────────────────────────────────────────────

   computePeaceScores(registry) 함수가 학생 활동을 자동 채점.

   차원                  점수 기준                          배점
   ──────────────────    ──────────────────────────────    ────
   Cognition 사실 이해    현장 단서 + 핵심 단서 수집량       0~3
   Connection 연결 의식   인과 사슬 + 자기성찰 + 본인 글     0~3
   Action 실천 다짐       UN 보고서 + UN 연설문 완성         0~3
   Cooperation 국제 협력  사건별 "협력의 손길" 단서 2종      0~3
                                                          ─────
                                                  총점    12점

   등급:  S (10+) · A (8+) · B (5+) · C
   교사 대시보드·인쇄 보고서·학습 트리 카드에 자동 반영.


■ 5. UNESCO 세계시민교육(GCED) 3영역과의 결합
   ─────────────────────────────────────────────────────────────

   PEACE 단계가 "사고 흐름"이라면 GCED 3영역은 "내용 분류".
   두 축이 직교(orthogonal)하므로 단계마다 영역이 섞임.

       PEACE \ GCED  │ 인지(■파랑)  정서(■주황)  행동(■초록)
       ──────────────┼─────────────────────────────────────────
       P 인식        │              ●
       E 탐색        │     ●        ●
       A 분석        │     ●        ●
       C 성찰        │     ●        ●            ●(맹아)
       E 실천        │                            ●

   · 모든 단서(사건당 15개)에 area 태그 부착 — 색상 배지로 시각화


■ 6. 교사 수업 활용 흐름
   ─────────────────────────────────────────────────────────────

   A. 한 사건 집중 (1차시 50분)
      ────────────────────────────────────────────
      시간   수업단계      PEACE         학생 활동
       5분   도입          ─             사진 1장·발문
      10분   인식          P             안내인 대화
      15분   관찰          E → A         현장 + 시민 인터뷰
      10분   성찰          C             인과 사슬 + 자기성찰
      10분   실천          E             UN 보고서 + 연설문

   B. 3사건 통합 패키지 (2~3차시)
      각 사건을 차례로 또는 모둠별로 분담. 마지막에 학습 트리
      에서 사건별 4차원 점수 비교 + 토론.

   ※ 교사 실시간 대시보드(dashboard.html)로 학급 진행도 추적
     - 학급 P.E.A.C.E. 종합 통계 패널 (등급 분포 + 4차원 막대)
     - CSV 내보내기 (19컬럼, UTF-8 BOM, Excel 호환)
     - 정체 학생 자동 강조 (같은 단계 5분+ 시 빨강 펄스)
   ※ 게임 내 「📑 교육과정 연계표」 화면을 자료집에 캡처 가능


■ 7. 2022 개정 교육과정 성취기준 매핑 (계획서 출처)
   ─────────────────────────────────────────────────────────────

   ▶ 사회과 — 지속가능한 세계와 글로컬 시민
   [9사(지리)12-01]  식량·에너지 자원의 소비·수입 현황을 분석
                     하여 자원의 지속가능한 확보 방안을 모색.
                                                 → 아랄해 핵심
   [9사(지리)12-02]  지역 개발과 환경 보존을 둘러싼 글로컬
                     환경 이슈에 관심·참여·실천.   → 아랄해
   [9사(지리)12-03]  더 나은 지역을 만들어 가는 사람들의 국내외
                     사례, 자기 지역 문제 해결 방안 모색·실천.
                                            → 코카랄 댐·UN·NGO

   ▶ 사회과 — 다양한 문화의 이해
   [9사(일사)02-03]  다양한 문화 사례 조사, 문화를 이해하는
                     바람직한 태도 토의.    → 팔레스타인 세 종교

   ▶ 사회과 — 국제 사회와 한반도
   [9사(일사)11-01]  국제 사회 행위 주체의 활동 조사, 국제
                     사회 특징 도출.            → 3사건 공통
   [9사(일사)11-02]  국제 사회의 다양한 분쟁 조사, 지역·국가·
                     세계 시민으로서 우리의 역할.→ 3사건 핵심

   ▶ 사회과 — 사회 변동과 사회문제
   [9사(일사)12-03]  사회 변동·사회문제에 대응하는 국내외 사례,
                     시민의 태도·실천 방안 토의.
                                          → UN 보고서·연설문

   ▶ 역사과 — 현대 세계의 전개와 과제
   [9역07-03]        오늘날 세계화의 양상을 조사하고, 성과와
                     과제를 탐구한다.    → 3사건의 글로벌 연결성
